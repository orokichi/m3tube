# M3Tube

Material 3 Expressive で作った多機能 YouTube クライアント（Next.js + youtubei.js / InnerTube）。

- データ取得: InnerTube（非公式 API）をサーバー側 `/api/yt` で呼び出し
- 再生: YouTube 公式 IFrame 埋め込みプレーヤー（youtube-nocookie）
- 機能: ホーム/検索/サジェスト/ショート/チャンネル/再生リスト/コメント（返信）/関連動画の無限スクロール、登録チャンネル・履歴・後で見る・高評価（ブラウザ保存）、続きから再生、再生速度、ループ、A-B リピート、スリープタイマー、シアターモード、SponsorBlock、Return YouTube Dislike、キーボードショートカット、ダイナミックカラー、ライト/ダーク自動、データのエクスポート/インポート

```
npm i
npm run dev
```
